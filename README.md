# Datos SEPA preparados para Changuito

Precios de Carrefour y Coto por celda de 0,1° × 0,1°, en el formato v1 del exportador (ver la rama `main`). Esta rama se reemplaza en cada corrida.

Fuente: **Precios Claros – Base SEPA**, Secretaría de Comercio Interior (datos abiertos, [datos.produccion.gob.ar](https://datos.produccion.gob.ar/dataset/sepa-precios)), licencia CC BY 4.0. Los datos se filtraron por cadena, se reorganizaron por zona y se aplicó la regla de promociones (descuentos de 70 % o más se descartan); no es una publicación oficial.
